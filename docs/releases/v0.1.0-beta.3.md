# 见舟画布录制 0.1.0-beta.3 · Windows / Mac Beta

本次将现有 Windows 与 Mac Beta 安装包统一整理到 GitHub Releases，提供固定下载入口。安装包沿用已有构建，没有重新编译应用。

## 下载哪个文件

| 系统 | Assets 中的文件 |
| --- | --- |
| Windows 10/11 x64 | `Jianzhou-Canvas-Recorder-Beta-0.1.0-beta.3-Windows-x64-setup.exe` |
| macOS 12+，Apple Silicon / Intel | `Jianzhou-Canvas-Recorder-Beta-0.1.0-beta.3-macOS-Universal.dmg` |
| PDF 使用手册 | `Jianzhou-Canvas-Recorder-User-Manual.pdf` |

Windows 双击安装程序；Mac 打开 DMG 后拖入“应用程序”。无需登录或配置 API Key。

## 功能

- Excalidraw 白板，PDF、图片、Markdown 和静态 HTML 演示。
- 激光笔与画笔批注、自动运镜、透明提词器。
- 摄像头画中画、麦克风测试、本地视频保存。
- 多种横竖画幅，优先 MP4，不支持时使用 WebM。
- 提词器、设置和录制控件不进入成片。

当前 beta.3 包含此前的 Mac 首次设备授权等待、摄像头兼容处理和诊断导出改进。详细用法见[仓库 README](https://github.com/tangchengjiao/jianzhou-canvas-recorder-build#readme)及随附手册。

## 使用提醒

- 当前为内测版，首次先录 10～20 秒，检查画面、声音与保存位置。
- Windows 安装包未做商业代码签名；Mac 包尚未完成 Apple 公证，首次打开可能需在系统隐私与安全设置中允许。
- Windows 缺少 WebView2 时，安装阶段需要联网下载运行环境。
- 30 分钟、2 小时真机长录尚未完成验收；PPT/PPTX 请先导出 PDF。
- 当前没有自动更新。后续版本从[同一个 Releases 页面](https://github.com/tangchengjiao/jianzhou-canvas-recorder-build/releases)获取。

Windows 安装后能力验证与 Mac 云端构建/启动已有记录，本次未重跑完整媒体回归，也未升级本机已安装的旧版。
