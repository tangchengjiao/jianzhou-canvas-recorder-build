# 见舟画布录制 · 用户使用手册

版本：0.1.0-beta.3　适用平台：Windows 10/11 x64、macOS 12 及以上

> 本软件完全本地运行，不需要登录，不需要配置 API Key，也不会自动上传画布、导入文件、提词稿、摄像头、麦克风或录制视频。

## 1. 先看这一页：5 分钟完成第一次录制

1. 安装并打开应用。
2. 点击右上角“设置”，选择画幅、录制区域和保存文件夹。
3. 如需声音或人像，分别打开麦克风和摄像头，并完成一次测试。
4. 点击“提词器”，粘贴脚本；拖动到镜头附近，按需要调速度、字号和透明度。
5. 直接在 Excalidraw 白板讲解，或从左侧“内容”导入 PDF、图片、Markdown、静态 HTML。
6. 点击“开始录制”，倒计时结束后开始讲解；需要时可暂停，再点击“结束”。
7. 在录制结果区回看并确认文件。优先生成 MP4；系统不支持时自动保存 WebM。

建议第一次只录 10～20 秒，确认画面、声音、摄像头位置、提词器速度和自动运镜后，再开始正式内容。

## 2. 安装与首次打开

### Windows

1. 双击 `Jianzhou-Canvas-Recorder-Beta-0.1.0-beta.3-Windows-x64-setup.exe`。
2. 当前内测包尚未购买商业代码签名，SmartScreen 可能显示“未知发布者”。只从发布者原始渠道获取，并核对 `SHA256SUMS.txt`。
3. Windows 10/11 通常已有 WebView2；缺失或版本过低时，安装器会联网下载微软官方运行环境。

### macOS

1. 打开 DMG，把应用拖到“应用程序”。
2. 当前内测包是 ad-hoc 签名、未完成 Apple 公证。首次打开若被拦截，进入“系统设置 → 隐私与安全性”，选择“仍要打开”。
3. 首次启用摄像头或麦克风时，在系统弹窗中点击“允许”。如果之前拒绝过，请在“系统设置 → 隐私与安全性 → 摄像头/麦克风”中重新开启，然后按 `Command + Q` 完全退出再打开。

## 3. 界面从哪里开始

- 中央：Excalidraw 白板或导入的讲解内容。
- 顶部中央：白板绘图工具；导入文档后会切换为指针、激光笔、画笔、荧光笔等讲解工具。
- 右上角：设置、提词器、开始/暂停/结束录制。
- 左侧“内容”：导入文件、切换页面、返回白板；可随时隐藏。
- 右侧工作台：画幅、选区、风格、画质、运镜、设备、保存位置、恢复中心和输出预览。
- 只有虚线录制区域内的合成画面会进入视频。提词器、状态标签、设置面板、内容侧栏和录制按钮都不会进入成片。

## 4. 录制设置

### 画幅与选区

- 预设：16:9、4:3、3:4、9:16、1:1；也可输入自定义宽高比。
- 点击“显示录制区域”可查看虚线边界；点击“编辑选区”后拖动或缩放，完成后再点击“完成选区”。
- 选区和控制界面不会进入视频。发布到短视频平台前，应预留字幕、头像和平台按钮的安全边距。

### 风格与画质

- 风格只改变最终输出背景，不会破坏白板或文档内容。
- 默认 720p 更轻量；1080p 更清晰，但显著增加显卡、内存和编码压力。
- 优先使用 H.264/AAC MP4；当前系统编码器不支持时自动回退为 WebM。

### 自动运镜

- 开启“划线时自动放大”后，使用自由书写、文档画笔或激光笔进行讲解时，输出预览与成片会平滑放大到当前动作区域。
- 监看时请以右侧“输出预览/大图预览”为准；白板本身不一定跟随放大。
- 强度建议先用“标准”，快速大幅移动时降低强度更自然。

## 5. 摄像头和麦克风

### 麦克风

1. 打开“录制麦克风”。
2. 选择输入设备；不确定时先用“系统默认”。
3. 点击“测试麦克风 6 秒”，看到电平变化后再录制。
4. 若没有声音，检查系统权限、输入设备是否被会议软件占用，并重新插拔设备后重启应用。

### 摄像头

1. 打开“摄像头画中画”，选择设备、形状、大小和镜像。
2. 直接拖动摄像头监看画面到安全位置；松手后位置会保存并同步进入成片。
3. 开始录制后位置会锁定，避免误触。
4. 默认在录制结束、切换标签页或未录制时离开当前窗口后关闭摄像头，减少误开与隐私风险。

## 6. 提词器

- 点击右上角“提词器”，把脚本粘贴到文本区。
- 拖动标题栏可自由移动；建议靠近摄像头，减少眼神偏移。
- 可调整滚动速度、字号、窗口背景透明度和文字透明度。
- “精简阅读”切换为双行透明字幕条，仍可自由移动和调宽；适合放在画面中部靠近镜头。
- 背景透明度可降到 0；文字透明度也可自行调整。
- 点击“播放/暂停”控制滚动；精简模式可使用 `Alt + 空格`。
- 提词器严格只用于监看，不会进入输出视频。

## 7. 白板讲解与激光笔

- 白板模式使用完整 Excalidraw 工具，可选择、移动、绘制形状、箭头、文字、图片和自由书写。
- 讲解动作需要进入成片时，使用自由书写或文档模式的画笔；激光笔轨迹也会参与实时录制和自动运镜。
- 只想指示、不想永久留线时，用激光笔；需要保留批注时，用画笔或荧光笔。
- 自动运镜只改变输出画面，不改变原始白板内容。

## 8. 导入 PDF、图片、Markdown 和 HTML

点击左侧“内容”，选择导入类型：

- PDF：保留页面视觉，支持翻页、批注和录制；最多 80 MB、200 页，过大的文件请先拆分。
- 图片：支持 PNG、JPEG、WebP、GIF、BMP、AVIF；最多 24 MB、单边 12,000px、24 百万像素。
- Markdown：适合课程大纲和长文，可选择横版/竖版、连续文档或按标题分页、纸白/暖纸/深夜主题。
- 静态 HTML：保留本地 HTML/CSS/SVG 的静态视觉，并自动把长页面拆成多页；脚本、表单、视频、外部网络资源会被禁用。上限为 5 MB 文本、200 个讲解画面。
- PPT/PPTX：当前推荐先在 PowerPoint、Keynote 或 WPS 中导出为 PDF，再导入应用；这样字体和排版更稳定。

HTML 如果黑屏或缺少样式，通常是因为它依赖 JavaScript、在线字体、远程图片或框架运行时。请先在浏览器中导出为“完全离线的静态 HTML”，把 CSS/图片放到同目录，或直接导出 PDF。

## 9. 正式录制、保存与回看

1. 在设置中确认保存方式：“指定文件夹”或浏览器下载。
2. 选择文件夹后，应用只在本次运行中保留写入授权；重启后需要重新选择。
3. 点击“开始录制”，倒计时结束后开始。
4. 录制中可暂停/继续；点击“结束”后等待封装完成，不要立即强制退出。
5. 输出优先为 MP4，不支持时为 WebM。剪映、VLC 或系统播放器均可尝试打开；编辑兼容性以 MP4 最佳。

选择指定文件夹并确认写入成功后，本机 OPFS 临时录制副本会自动清理。若使用浏览器下载或保存中断，恢复中心可能保留分片，以便导出抢救；确认不再需要后可手动删除。

## 10. 隐私与安全

- 不需要账号、手机号、邮箱、云端服务或 API Key。
- 没有自动遥测、广告或上传接口；应用运行时只处理本机内容。
- 摄像头和麦克风只在你主动开启或测试时访问。
- 导出诊断日志是手动操作，且会移除文件名、目录名、本机路径、会话标识、设备指纹、链接、邮箱和凭据样式内容。
- 设置页可随时点击“清除本机诊断记录”。即使日志已经脱敏，发送给他人前仍建议自己打开快速检查。
- 不要分享开发目录、原始测试报告、恢复分片或包含自己课程内容的截图。

## 11. 常见问题

### 摄像头/麦克风打不开

检查系统权限 → 关闭 Zoom、会议网页、FaceTime、OBS 等占用软件 → 选择“系统默认”重新测试 → 完全退出应用再打开。macOS 需重点检查“系统设置 → 隐私与安全性”。

### 开始录制后闪黑、卡倒计时或崩溃

先关闭摄像头和麦克风录 10 秒；成功后逐项开启。把画质改为 720p，关闭其他录屏/会议软件，减少导入文件体积。结束时等待“正在保存”完成。

### 提词器太快或不动

先点击“回到开头”，把速度调到低档再播放；确认文本高度超过窗口。精简模式可用 `Alt + 空格` 播放/暂停。

### 自动运镜没反应

确认“划线时自动放大”已开启，实际按住鼠标/笔完成连续划线，并观察“输出预览”而不是只看原白板。

### WebM 打不开或不好编辑

优先使用 VLC 播放；剪辑时可用剪映/FFmpeg 转成 H.264 MP4。下一次录制前检查输出预览是否显示“MP4 优先”。

### 保存文件找不到

指定文件夹模式保存到你当次选择的目录；否则进入系统默认下载目录。设置页会显示当前保存方式。重启应用后需要重新选择目录。
